## 1. Notification history center (b6bb1bf — new)

The review surface over `Services/Notifs.qml`'s history buckets, which the
service (and omarchy's comments) always anticipated but no UI ever served.

- **Panel** (`Modules/Bar/widgets/NotifsPanel.qml`): a BarPanel flyout in
  the Bluetooth panel's idiom — hero row (bell glyph, "Notifications",
  mono meta line, DND PanelSwitch), then one ListView over both buckets:
  UNSEEN (pending) and RECENT (past, the 15-minute replay window), each
  under a SectionHeader with a CLEAR affordance. Rows: icon/image/glyph
  slot, summary (error-colored when critical), body preview, relative
  timestamp (ticks on a 30 s timer *only while open*), hover/cursor
  dismiss button (MouseArea-grab variant), and action chips while the
  sender's live notification still exists. Closing the panel marks all
  pending seen, so the bell badge is an honest unseen counter.
- **Keyboard**: j/k/arrows move the cursor (−1 is the hero DND switch),
  Enter/Space invokes the row's default action or focuses the sender's
  window (click does the same), x/Delete dismisses, D toggles DND, Escape
  closes (BarPanel standard). Right-click a row dismisses it.
- **Bell** (`Modules/Bar/widgets/NotifsBell.qml`): BarIndicator in the dnd
  family, `notifs` in the Indicators default order (also registered as a
  standalone bar widget id). Lit with an accent count badge
  (TailscaleIcon's punched-pill recipe) while unseen notifications wait;
  revealed on hover otherwise. Click toggles the center. Hosted bells
  delegate the panel to the Indicators container so an active-block copy
  tearing down (last unseen cleared) cannot close an open panel.
- **IPC**: `qs ipc call notifs toggle|show|hide` (`show` from a terminal
  needs `-- show` or `toggle` — the known qs CLI collision), routed
  service → shellRoot → Bar, focused output first. All existing verbs
  unchanged.
- **Keybind**: `Mod+Ctrl+Alt+Comma` — "Notification Center", the last free
  chord in the comma family. The old `Mod+Shift+Alt+Comma` toast replay
  stays untouched.
- **Loading**: the panel compiles on first open via the widget-panel
  `Loader.setSource` rule; nothing new is eager in shell.qml.
- Screenshots taken during verification: empty state ("ALL CAUGHT UP"),
  populated state (1 unseen critical + 2 recent), bar bell with badge.

## 2. Nightlight temperature (4343470 — enhancement)

Nightlight itself (service, wlsunset, menu Style toggle, bar indicator,
`Mod+Ctrl+N`) shipped in the parity batch. New: the state file's *content*
is the night temperature. `qs ipc call nightlight temperature 3500` or
`echo 3500 > ~/.local/state/qshell/nightlight` bounces the daemon at the
new warmth (wlsunset has no control channel, so a new temperature is a new
process); empty file keeps upstream's 4000 K; re-enabling writes the
remembered warmth back so off/on keeps a custom value. Chosen over inline
widget settings because the flag file already survives shell restarts and
already has a watcher — no second store, no polling. Note: this MacBook's
eDP-1 reports no gamma table (`gammaSupported: false` in status), so the
warmth only shows on external displays — pre-existing hardware limit the
service already reports.

## 5. Tiered battery low-warnings (3236f9d — new)

The single 10 % critical latch became a ladder: 20 % normal, 10 % and 5 %
critical, deepest-crossed-rung-only, once per discharge, re-armed by
leaving the discharge state. Skips machines whose UPower display device is
not a laptop battery. Event-driven off UPower's own change signals — no
timers (upstream polls every 30 s; we must not). Verified with temporary
rungs at the real 52 % level: normal toast, exactly one critical toast for
a two-rung crossing, silence after restoring the real ladder.
