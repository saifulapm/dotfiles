# Background blur (2026-08-06)

Opt-in compositor blur for niri 26.04 + quickshell 0.3, off by default.
Toggle: menu → Toggle → Blur, `qs ipc call blur toggle`, or
`touch`/`rm ~/.local/state/qshell/blur` (the flag file is the state,
nightlight's shape — Services/Blur.qml).

## Why this design is the fast one

- **Xray blur only.** niri blurs the wallpaper once into a cached texture and
  every blurred surface is then a single textured quad; the cache invalidates
  only on wallpaper damage, scale or config change. The non-xray mode (blur
  the live content beneath) is experimental, does a mid-frame framebuffer
  readback per surface per frame, and vanishes during open/close animations —
  nothing here requests it. Global tuning stays at niri's defaults
  (passes 3, offset 3; offset is free GPU-wise, passes are not).
- **Client-shaped regions, zero layer-rules.** Shell surfaces request blur via
  `BackgroundEffect.blurRegion` (ext-background-effect-v1), shaped exactly
  like the card with matching corner radius — so a fullscreen overlay frosts
  only its card, never the scrim. niri grants protocol-requested blur with no
  compositor config; a rule-based approach would frost the entire overlay
  surface.
- **Disabled = nothing.** No region published, no niri rules emitted, opaque
  fills — the only standing cost is one file watcher. Verified: RSS and idle
  CPU unchanged after the feature (204 MiB / 0.28%).

## Pieces

- `Services/Blur.qml` — flag watcher, IPC target `blur`
  (status/enable/disable/toggle), renders
  `~/.local/state/qshell/niri-blur.kdl` on state change: a
  `background-effect { blur true }` window-rule plus 0.95/0.90 opacities
  (the base 0.985/0.96 is too opaque for frost to read). config.kdl includes
  the fragment `optional=true` after the theme include; niri live-reloads
  included files, so toggling never restarts anything.
- `Theme.blurActive` + glass: section cards go through `sGlass`
  (bar/panel/menu/osd/notifications/polkit backgrounds), base-token cards
  through `theme.glass()`. Glass alpha defaults to 0.8; themes may retune
  globally (`[blur] alpha`) or per surface (`background-blur-alpha`).
- Regions on: bar strip, BarPanel card, launcher, menu, emojis, clipboard,
  file picker, reminder flow, OSD pill, notification toasts (per-toast child
  regions pushed into one union — a column-shaped region would float blurred
  rectangles in the transparent gaps), polkit card + justification pill.
- Deliberately skipped: tooltips and tray menus (xdg pop-ups default to the
  experimental non-xray path), lock (niri won't blur lock surfaces), the
  filmstrip pickers and network QR/speedtest overlays (free-form content over
  a deep scrim, no card to glass).

## Verified on screen

Launcher/calendar cards frost with rounded corners over the wallpaper while
the scrim stays a plain dim; app windows show the wallpaper bloom at 0.95;
disable restores full opacity and rewrites the fragment (niri reload logged);
toggle round trip leaves the log clean.
