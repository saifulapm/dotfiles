# The 2026-08-26 refactor — perf, theming character, vicinae

Four commits, one session: `4457beb` (audio mic), `e991839` (perf),
`41edf1c` (theming), `98f18e1` + `1af38b7` (vicinae switch + lean binds).

## Audio panel never wakes the microphone

The input peak meter was a real `PwNodePeakMonitor` capture stream, and a
`pw-record → /dev/null` process forced Bluetooth mics into HFP for it.
Both removed; the INPUT section keeps its slider and source picker.
(Omarchy's panel still ships the meter — deliberate divergence.)

## Shell performance

- **`Modules/Bar/components/PanelLoader.qml`** — every bar flyout loader
  tears its panel down 45 s after it closes (same policy as shell.qml's
  SurfaceLoader). Before: ~20 panel trees, each with a CardFrost blur
  chain and a Wayland surface, latched resident forever after one open.
- Vector bar icons (devservices/dropbox/warp) draw with
  `Shape.CurveRenderer` instead of a permanent 4×MSAA layer FBO each; the
  tray drawer rows keep their layer only while the drawer is sliding.
- AutoBrightness stretches its 5 s sysfs sampling to 15 s after six stable
  lux ticks; any change/mismatch/retry snaps it back. Applies only ever
  happen on ticks, so manual-override behavior is unchanged.

## Theming: every theme has a character

Schema (documented in `themes/tokyo-night.toml`; merge order builtin <
preset < theme < `~/.config/qshell/theme-override.toml`):

- `[meta] preset` — a bundle from `shell/Commons/presets.js`:
  `flat` `glass` `shaded` `playful` `calm` `snap` `still`.
- `[blur]` enabled/alpha/noise/saturation, `[opacity]`
  active/inactive/blur-active/blur-inactive, `[shadow]`
  enabled/softness/spread/offset-x/offset-y/color, `[motion]` +
  open-ms/open-curve/close-ms/close-curve/spring-damping/
  spring-stiffness/workspace-stiffness, `[border] active` gradients.
- Three theme-apply emitters render it all into
  `~/.local/state/qshell/niri-theme.kdl`: `niri_shadow`, `niri_opacity`
  (the base opacity pair moved OUT of config.kdl; the media exemption is
  re-stated after it because the latest matching rule wins),
  `niri_animations` (full per-theme blocks — named curves or raw
  cubic-bezier, spring damping/stiffness; duration 0 = `off`).
  KDL gotcha: `damping-ratio` must be a float literal (`1.0`, never `1`).
- **Blur flag is tri-state now**: `~/.local/state/qshell/blur` holding
  `on`/`off` is a user override; absent means follow the theme (legacy
  empty file = on). `qs ipc call blur auto` clears the override.
  Blur.qml renders the fragment from theme tokens and re-renders on theme
  switches; theme-apply mirrors the same rule for the foot-alpha symlink.
- All 22 themes assigned presets; 14 gained palette-built gradient
  borders; `theme-from-image` emits `glass` + a gradient.

## Vicinae owns launcher, command palette, clipboard

Installed from COPR `quadratech188/vicinae` (auto-tracks upstream,
f44 aarch64, system Qt). Our pieces:

- `~/.config/vicinae/overrides.json` + a theme-generated fragment, loaded
  via `VICINAE_OVERRIDES` in our `vicinae.service` (shadows the packaged
  unit; `--no-extension-runtime` = no node). `settings.json` stays
  vicinae-owned. Every provider off except apps, clipboard, scripts.
- Themed: theme-apply renders `~/.local/share/vicinae/themes/qshell.toml`
  and pokes `vicinae theme set qshell` (the deterministic reload).
- **70 script commands** in `~/.local/share/vicinae/scripts` carry the
  whole old Menu surface. Metadata format is `# @vicinae.key value` —
  NO equals sign (the upstream doc comment lies).
- Clipboard: capture via `ext-data-control-v1` (niri-native, honors the
  password-manager hint → `pass` stays out of history), paste-into-window
  via the rpm's capability-blessed input server (terminal chord picked by
  the target's TerminalEmulator desktop category — windows with synthetic
  app-ids get the GUI chord). Tailnet clipboard sync untouched; a
  re-copy from vicinae history fans out to the tailnet like any copy.
- Retired: `Modules/Launcher` `Modules/Menu` `Modules/Clipboard`,
  `clipboard-capture/-paste/-open`. `menu-select` = `vicinae dmenu`;
  `menu-input` = themed gum in a float (dmenu has no free-text answer).
  Old history remains at `~/.local/state/qshell/clipboard/` — delete when
  comfortable. The Emojis picker stays in-shell.

## Keybindings: zero three-modifier chords

All 44 removed. `Mod+Space` = vicinae. `Mod+Ctrl+V` = clipboard history.
`Mod+Alt+arrows` = move-column-to-monitor. Everything niche (bar panel
digits, notification center, OCR-speak, cast pick, silent workspace
moves, incognito, …) is fuzzy search now. Daily set kept: window/workspace
management, apps (Mod+T/E/N/…), audio/network/battery panels on
Mod+Ctrl+A/W/P, capture row Mod+Shift+3–7, media/hardware keys.
